# Hive Product Definition

## Positioning

Hive is a premium local-first knowledge and reasoning workspace for Apple users. It is not a generic chat shell, not a cloud-first note clone, and not a growth-hacked SaaS dashboard.

Core promise: your sources stay yours, your memory model stays inspectable, and the app behaves like a serious native Apple tool.

## Audience

- People managing dense personal and professional source material
- Users who need durable synthesis instead of disposable chats
- Teams or individuals who care about local control and auditability

## Product lane

- Local-first by default
- Cloud is explicit, optional, and review-gated
- Structured memory over novelty effects
- Confidence and provenance over style-only output

## Brand and tone

- Calm, precise, restrained
- No hype copy, no generic AI bravado, no novelty claims
- Language should read like a trusted tool used every day

## Dark-first visual language

- Primary visual baseline is dark mode
- Light mode is supported but follows the same structural hierarchy
- Contrast, typography, and spacing must remain legible at all times

## One-accent-color rule

- One accent only: warm amber family
- Accent color indicates intent and action, not decoration
- Do not introduce competing purple/blue gradient accents

## Anti-references

Do not imitate:

- Generic SaaS admin panels
- Neon gradient AI landing aesthetics
- Chat-first interfaces with no evidence model
- Over-animated “agent theater” UI

## Icon and menu bar seriousness

- Dock icon and menu bar icon must be intentional and consistent
- Menu bar behavior must reflect real capture state
- Icon quality is a product trust signal, not optional polish

## Non-generic UX expectations

- Every visible control must perform a real action
- Empty states must explain purpose and next step
- Re-indexing and ingestion must expose status honestly
- Error states must provide recovery paths, not dead-end alerts

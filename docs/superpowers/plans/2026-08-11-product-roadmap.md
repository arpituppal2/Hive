## Guiding principles

1. **The browser is the wedge; memory is the moat; action is the revenue.** Every quarter ships one browser-credibility item AND one memory item — credibility earns trust, memory compounds it.
2. **Demo-first.** The YC demo gate (Q3) defines the end state; every milestone after it extends the compound workflow, never replaces it.
3. **Progressive disclosure.** Browse → Remember → Ask → Organize → Act → Extend. No dashboard-first launches (AGENTS.md §2.4).
4. **Local-first is a product property, not a slogan** (DEC-004): offline behavior, provenance, export, deletion, and honest model labels are acceptance criteria in every milestone.
5. **Every consequential change is reversible** (DEC-007) and audited (EventLedger).
